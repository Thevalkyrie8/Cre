# Welcome to the GitHub Pages Course!

This is a hands-on course that teaches you how to create a site or blog from your GitHub repositories using GitHub Pages.

## How This Course Works

This course is designed to run interactively on GitHub, but you can preview the content locally for development purposes.

### Course Steps

1. **Enable GitHub Pages** - Learn how to turn on GitHub Pages for your repository
2. **Configure Your Site** - Set up Jekyll and themes
3. **Customize Your Homepage** - Add your own content
4. **Create a Blog Post** - Learn Jekyll's blogging features
5. **Merge Your Pull Request** - Complete the course

## Local Development

You're currently viewing this course in local development mode. To run the full interactive course:

1. Push this repository to GitHub
2. Enable GitHub Pages in your repository settings
3. The GitHub Actions workflows will guide you through each step

## Quick Start

To continue developing locally:

```bash
# Install dependencies
bundle install

# Start the Jekyll server
bundle exec jekyll serve

# Visit http://localhost:4000
```
